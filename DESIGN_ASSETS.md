# ClipboardWarrior visual assets

## Added in this redesign

- The popover no longer shows a branded header, so the `BrandMark` image set was removed. The source artwork remains in `ExtraIcons/`.
- `ClipboardWarrior/Assets.xcassets/AccentColor.colorset`: sets the shared app accent to the red from the ClipboardWarrior shield artwork.
- `ClipboardWarrior/DesignSystem.swift`: shared semantic colors and a reusable material card surface modifier for future Archive, Boards, and Settings styling.

The menu-bar navigation uses SF Symbols: `clock`, `pin.fill`, and `square.grid.2x2.fill`. Each icon retains a tooltip and accessibility label.
